# Scriptorium Portadas — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cada libro puede tener una portada (`coverUrl`). Se precarga desde Google Books, se edita a mano en el formulario y se ve en la card, con placeholder si falta o si la imagen falla.

**Architecture:** Se guarda solo la URL en una columna nueva de SQLite. La base existente se migra con un `ALTER TABLE` idempotente en `openDb`. Zod valida que la URL sea `http` o `https`. El adaptador de Google suma la miniatura al candidato. En el front, `book-card` y `book-form` muestran la imagen con un fallback, que se activa con el evento `error` del `<img>`, y `book-lookup` muestra miniaturas en los resultados.

**Tech Stack:** el mismo de los ciclos anteriores: Node 24, Express 5, better-sqlite3 12, zod 4, Vitest 4 + supertest; Angular 22 (standalone, signals, zoneless) con Vitest. No se agregan dependencias.

**Spec:** `tp-final/docs/superpowers/specs/2026-10-13-portadas-design.md`

## Global Constraints

- Todas las rutas de archivo son relativas a `tp-final/`. El repo git es el padre `riverosk-iisaia/`. Rama: `feature/portadas`.
- Campo: `coverUrl: string | null`.
  - En las respuestas va siempre, como `null` si no hay portada; nunca se omite.
  - En POST y PATCH es opcional y acepta `null`.
- Validación de `coverUrl`:
  - primero se recortan los espacios;
  - después tiene que ser una URL con protocolo `http` o `https` y de `2000` caracteres como máximo;
  - si no cumple → 422 `VALIDATION_ERROR` con `fields.coverUrl`.
- Google: se usa `volumeInfo.imageLinks.thumbnail`; si no está, `smallThumbnail`; si no hay ninguna, `null`. Un `http://` al principio pasa a `https://` y el resto de la URL queda igual.
- Tamaños: portada en la card y vista previa del formulario de 80×120 px con `object-fit: cover`; miniatura de los resultados de Google de 32×48 px.
- Textos exactos de la UI:
  - label del campo: `URL de portada`;
  - error de la vista previa: `No se pudo cargar la imagen`;
  - `alt` de la portada en la card: `Portada de {título}`;
  - miniatura de los resultados: `alt=""`.
- Todo `<img>` de portada lleva `referrerpolicy="no-referrer"`. El de la card lleva además `loading="lazy"`.
- El placeholder es la inicial del título en mayúscula, con `aria-hidden="true"` y fondo `#f5f5f5`.
- Paleta: #2d5016, #558b2f, #7cb342, acento #fbc02d, fondo #f5f5f5; Courier New; bordes de 2px a 4px.
- Las reglas de negocio no cambian: `resolve()` solo suma el default `coverUrl: null`.
- El contrato `api/openapi.yaml` se actualiza **antes** que el código.
- TDD: cada test se ve fallar antes de escribir el código.
- Commits en español con prefijo `TP final:`. **Sin línea `Co-Authored-By`.** No commitear el `.DS_Store` de la raíz.
- Comandos:
  - en `api/`: `npm test` y `npx tsc --noEmit`;
  - en `web/`: `npx ng test --watch=false` y `npx ng build`;
  - contrato: `npx @redocly/cli@latest lint openapi.yaml` desde `api/`.

## Review Focus

1. Una URL con espacios a los costados (`"  https://x/y.jpg "`) se guarda recortada y no da 422. Test en Task 1.
2. En "Editar", borrar el texto de la URL y guardar manda `coverUrl: null`, y la portada desaparece. Test en Task 4.
3. Una miniatura de Google con query string (`http://books.google.com/books/content?id=X&printsec=frontcover&img=1&zoom=1`) llega igual, solo con `https`. Test en Task 2.
4. Si el título empieza con espacios o con una minúscula acentuada (`"  ángel"`), el placeholder muestra `Á`. Test en Task 3.
5. Si la vista previa del formulario falló y el usuario corrige la URL, la vista previa vuelve a intentar cargar en lugar de quedarse en el error. Test en Task 4.

- [ ] **Step 2: Tests que fallan.**
  - `db.test.ts`:
    - El test "crea la tabla books en memoria" ahora espera la lista de columnas con `'coverUrl'` al final.
    - El test de reabrir el archivo pasa a nombrar las columnas en el `INSERT`, porque la tabla ahora tiene 11.
    - `migra una base vieja sin coverUrl conservando las filas`:
      - en un archivo temporal se crea a mano la tabla con el esquema anterior, de 10 columnas, y se inserta una fila;
      - `openDb(path)` agrega la columna;
      - `SELECT coverUrl, title` devuelve `{ coverUrl: null, title: 'T' }`.
    - `abrir dos veces una base ya migrada no falla`.
  - `books.create.test.ts`:
    - un POST sin `coverUrl` responde con `coverUrl: null`;
    - con `'https://example.com/c.jpg'` → 201 con ese valor;
    - con `'http://example.com/c.jpg'` → 201;
    - con `'  https://example.com/c.jpg  '` → 201, guardado como `'https://example.com/c.jpg'` (Review Focus 1);
    - `test.each` con `'ftp://example.com/c.jpg'`, `'javascript:alert(1)'`, `'no es url'` y `'https://example.com/' + 'a'.repeat(1981)` (2001 caracteres) → 422 con `fields.coverUrl` definido.
  - `books.update.test.ts`:
    - PATCH `{ coverUrl: 'https://example.com/c.jpg' }` lo setea;
    - después, PATCH `{ coverUrl: null }` devuelve `coverUrl: null`.

  Correr `npm test`. Esperado: FAIL.

- [ ] **Step 3: Implementar.**
  - `db.ts`: el `CREATE TABLE` suma `coverUrl TEXT` al final. Después lee `PRAGMA table_info(books)`; si no aparece `coverUrl`, corre `ALTER TABLE books ADD COLUMN coverUrl TEXT`.
  - `books.schema.ts`: `coverUrl` es un string que se recorta, con largo máximo 2000, que valida como URL con protocolo `^https?$` (en zod 4, `z.url({ protocol: /^https?$/ })` o algo equivalente). Es `.nullable().optional()`.
  - `books.repo.ts`: sumar `coverUrl` a `Book`, al `INSERT` y al `UPDATE`. Como el `SELECT *` ya trae la columna, no hace falta tocarlo.
  - `books.routes.ts`: sumar `coverUrl: null` a `DEFAULTS`. Nada más.

- [ ] **Step 4: Verificar.** Correr `npm test` y `npx tsc --noEmit`. Esperado: todo PASS y tsc limpio.

  - `BookInput` incluye `coverUrl` porque el `Pick` suma la clave.

- [ ] **Step 1: Tests que fallan** (en `book-card.spec.ts`, un host con `book = signal<Book>(...)`):
  - `con coverUrl muestra la imagen`: hay un `img` con `src` igual a la URL, `alt === 'Portada de Dune'`, `loading === 'lazy'` y el atributo `referrerpolicy === 'no-referrer'`. No hay `.cover-placeholder`.
  - `sin coverUrl muestra el placeholder con la inicial`: no hay `img` y `.cover-placeholder` tiene texto `D` y `aria-hidden="true"`.
  - `si la imagen falla muestra el placeholder`: se hace `img.dispatchEvent(new Event('error'))` y, después de `detectChanges`, aparece el placeholder y ya no está el `img`.
  - `al cambiar coverUrl vuelve a intentar`: después del error, `book.set({ ...b, coverUrl: 'https://otra/c.jpg' })` vuelve a mostrar un `img` con la URL nueva.
  - `la inicial ignora espacios y va en mayúscula`: con título `'  ángel'`, el placeholder muestra `Á` (Review Focus 4).

  Correr `npx ng test --watch=false`. Esperado: FAIL.

- [ ] **Step 2: Implementar.**
  - **Lógica:**
    - `coverFailed = signal(false)`, que vuelve a `false` cuando cambia `book().coverUrl`. Puede ser un `linkedSignal` o un `effect`.
    - `initial = computed(...)`: primer carácter de `title.trim()`, pasado con `toLocaleUpperCase('es')`.
    - El `<img>` va solo si hay `coverUrl` y no falló, con `(error)="coverFailed.set(true)"`. Si no, va el `<div class="cover-placeholder" aria-hidden="true">`.
  - **Layout:** la portada va a la izquierda del contenido actual, en 80×120 con borde de 2px `#558b2f`. Con menos de 480 px de ancho, va arriba del contenido.
